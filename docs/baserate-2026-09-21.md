# Base rate, 2026-09-21

Stage 1 of `docs/design.md`: how much of the waste jev-save targets exists in the author's own Claude Code
sessions, before any Jev call. Produced by `tools/extract-corpus.mjs --days 30` and `tools/baserate.mjs`
over `~/.claude/projects` (97 transcripts, 30 days). Counts and redacted commands only.

| | value |
| --- | --- |
| sessions / turns / tool calls | 93 / 2,504 / 11,557 |
| turns with at least one tool call | 1,544 (median 4 calls, p90 17, max 243) |
| checks (test/build/lint runners as the command's own verb) | 241 = 2.1% of tool calls; test 195, lint 46 |
| sessions with any check | 44 of 93 |
| check duration, median | 14.8 s |

| of those a plain runner | 3 |

| identical read/search repeated with nothing changed between | 14 of 3,504 = 0.4% |

Tool calls by kind: write-bash 32% · read 20% · other (scripts, subagents) 19% · external (web, MCP) 13% ·
search 10% · edit 3% · check 2% · vcs 0.2%.

## Reading

- The redundant-verification target is small here: sixteen candidates in a month, thirteen of them already
  answered by Click's receipt reuse at 0.7 s each. Even as an upper bound, enforcing `RETRY` on redundant
  checks would save about five minutes per month on this corpus.
- Checks are rare in absolute terms (2% of calls). Time goes to shell scripts, reads and external calls.
- The corpus is one person's and unusual: many sessions were driven in a bash-first style with scratchpad
  scripts (the `write-bash` and `other` mass), and the Click sessions already dedupe checks. Other users'
  sessions may look different; the numbers should be reproduced on at least one other corpus before deciding.

## Caveats (also printed by the tool)

- "Still valid" here means no edit, shell write or unclassified shell command in the transcript since the
  pass. Edits made outside the agent are invisible, so candidate counts are an upper bound.
- A repeat after a new prompt is excluded: the user may have asked.
- Durations are wall time between `tool_use` and its result, including any wait for permission prompts.
- Subagent transcripts are not folded in yet.
